# 达人与素材行为

## 标签

目标规则：TIANTI 不再维护达人标签。后台输入、批量动作、公开展示、筛选、搜索权重、首页标签入口、领域字段及数据库标签数据均应移除。升级到 5.1 时删除既有标签数据。

## 抖音资料

- 抖音同步只维护达人主页、简介、粉丝数和主页行程；不抓取或展示最新作品、关联小号。
- 新增或编辑达人时，后台提供“打开抖音搜索”快捷窗口，并把当前昵称带入搜索；编辑人自行进入正确主页复制链接，再粘贴主页 URL 或完整分享文案，系统自动提取和规范化。
- 编辑人解除抖音主页后，历史同步资料保留用于恢复和审计，但立即停止公开展示；重新绑定主页并成功同步后才恢复公开展示。
- 主页行程以最近一次成功同步的个人简介为当前快照；简介中仍存在的行程即使过期也公开展示，已从简介移除的旧行程不再展示。最近一次同步失败但主页仍绑定时，继续使用上一次成功快照。
- 抖音同步不得根据主页行程创建、匹配、合并或更新活动及阵容。既有未来抖音自动阵容应移除；无现场档案和人工阵容的未来纯自动活动应删除；过去活动、已有现场档案的活动、人工活动和既有合并活动保留为普通内容。
- 后台不再提供活动合并功能；既有合并活动转为普通人工活动，不尝试恢复已删除的来源活动。历史合并规则数据可保留但不再参与运行时行为。
- Production 每 6 小时在北京时间 00:23、06:23、12:23、18:23 触发一次抖音全量同步；Preview 继续通过后台手动同步验收。

## 地点行程浏览

- 公开活动页提供独立于活动筛选的地点行程入口，以弹窗展示结果；它只读取符合公开资格的当前主页行程，不依赖活动或阵容数据。
- 地点选择支持省级地区和城市，不提供“全国”汇总项。全国省级与地级地点使用内置映射归属；无法识别的地点不提供筛选入口，但可以出现在已入选达人的完整行程原文中。
- 达人只要有一条主页行程命中所选地点即可入选；入选后展示该达人的全部主页行程，并突出命中项、弱化过期项。
- 达人及其内部行程按日期距今天的绝对天数升序排列；距离相同时未来优先于过去，无日期行程最后。

## 非破坏性取景与上传

- 每张新素材只保存一份包含完整构图的源图及其取景参数，不生成裁剪后的第二份图片。
- 取景参数包含显示比例和源图内的归一化区域；公开页面、后台预览和再次编辑使用同一参数。
- 达人代表图统一使用竖版 3:4 取景；历史横版代表图保留完整源图，但展示和再次编辑时按竖版 3:4 处理。
- 再次编辑只更新取景参数，不重新上传对象。历史上已物理裁剪的素材以现有文件作为完整边界，无法恢复更早已删除的画面。
- 超大图片在浏览器内缩至最长边 3200px 并高质量编码；无需缩小的图片保持原格式。优先通过预签名 URL 直传 R2 并自动重试，直传不可用时回退服务器上传。

## 孤立素材清理

- 每次自动清理持久化运行时间、扫描数、候选数、删除数和错误数，后台可查看最近一次结果。
- 对象存储删除失败不能丢失重试依据；后续运行应继续尝试，直到对象和数据库状态一致。
