# TIANTI 领域词汇

## 达人与抖音资料

**达人**：
TIANTI 中被展示、参与活动并可被编辑人记录的内容主体。

**抖音主页**：
唯一指向某位达人主抖音账号的可验证个人主页链接。它不是任意带“抖音”文字的平台链接。
_避免称为_：抖音链接、大号链接

**最新作品**：
达人按实际发布时间计算的最新一条公开抖音作品，包含视频或图文，不受主页置顶顺序影响。
_避免称为_：主页第一条、置顶作品

## 素材维护

**孤立素材**：
超过保护时间且未被达人资料或活动档案引用的素材记录及其对象存储文件。
_避免称为_：未使用图片、临时图片

**非破坏性取景**：
素材保留完整画面，编辑操作只选择公开页面展示的区域；再次编辑时可以在保留画面范围内重新缩放和移动。
_避免称为_：裁剪图片、生成裁剪图

**素材清理运行**：
一次自动扫描并处理孤立素材的维护过程，具有可查询的运行时间、扫描数、删除数与错误数。
