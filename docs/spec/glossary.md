# TIANTI 领域词汇

## 达人与抖音资料

**达人**：
TIANTI 中被展示、参与活动并可被编辑人记录的内容主体。

**抖音主页**：
唯一指向某位达人主抖音账号的可验证个人主页链接。它不是任意带“抖音”文字的平台链接。
_避免称为_：抖音链接、大号链接

**颜值梯度**：
某位编辑人针对达人在一次现场活动档案中的 T0～T5 整数等级评价；T0 为最高级，编号越大等级越低。既有档案可以未评分，未评分不参与曲线或平均值计算。
_避免称为_：达人固定梯度、活动评分

**平均梯度**：
某位达人在某位编辑人视角下，全部已评分现场档案的颜值梯度算术平均值，以带 `T` 前缀的一位小数展示；数值越小等级越高。两位编辑人的平均梯度分别计算，不合并为单一全站分数。
_避免称为_：综合梯度、全站平均分

**粉丝量梯度**：
按达人已同步的抖音粉丝数自动划分的区间：100 万以下、100～200 万、200～300 万、300～500 万、500 万以上；区间采用左闭右开，500 万以上包含 500 万。没有可靠粉丝数的达人归入“粉丝数未知”。
_避免称为_：手动粉丝档位、粉丝排名

**平均梯度区间**：
按某位编辑人的平均梯度自动划分的区间；使用 T0～T1、T1～T2、T2～T3、T3～T4、T4～T5，其中 T0～T1 最高，没有有效评分的达人归入“暂无评分”。
_避免称为_：手动平均档位、双编辑综合分组

**主页行程**：
达人最近一次成功同步的抖音个人简介中仍然存在的行程；只要仍在当前简介快照中，即使日期已经过去也属于主页行程。
_避免称为_：自动活动、历史提取记录

**行程地点筛选**：
根据主页行程中识别出的省级或城市地点筛选达人；达人只需有一条行程命中所选地点，展示时仍呈现该达人的全部主页行程。
_避免称为_：活动地点筛选、全国行程榜

## 素材维护

**孤立素材**：
超过保护时间且未被达人资料或活动档案引用的素材记录及其对象存储文件。
_避免称为_：未使用图片、临时图片

**非破坏性取景**：
素材保留完整画面，编辑操作只选择公开页面展示的区域；再次编辑时可以在保留画面范围内重新缩放和移动。
_避免称为_：裁剪图片、生成裁剪图

**素材清理运行**：
一次自动扫描并处理孤立素材的维护过程，具有可查询的运行时间、扫描数、删除数与错误数。

## 后台工作台

**对象索引**：
后台左侧用于搜索、筛选和选择达人或活动的独立滚动列表；选择对象只改变当前查看对象，不等于开始编辑。
_避免称为_：侧边栏、编辑列表

**详情检查器**：
后台右侧持续展示当前对象摘要、状态和快捷动作的工作区域；编辑是从检查器发起的独立动作。
_避免称为_：详情弹窗、右侧卡片

**批量模式**：
勾选一个或多个对象后进入的显式操作状态；当前查看对象与已勾选对象是两套独立状态。
_避免称为_：多选状态、批量勾选
